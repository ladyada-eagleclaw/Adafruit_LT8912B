bool Adafruit_LT8912B::begin ( TwoWire *  wire = &Wire,

)

Initialize I2C control and optionally perform a physical reset.

Parameters
wireI2C bus, configured for the board's control pins by the sketch.
resetPinActive-low reset GPIO, or 0xFFFF to leave reset to the caller.
Returns
True when all three fixed addresses (0x48, 0x49, 0x4A) acknowledge.
Note
This checks acknowledgements, not silicon identity: no chip-ID check is implemented. Disconnect the adapter's DDC switch before calling this method; a monitor's DDC/ISP devices can collide with the bridge register addresses.

◆ configure()

bool Adafruit_LT8912B::configure ( const LT8912B_Timing &  timing,
uint8_t  lanes = 2 
)

Configure RGB888 DSI reception and enable video-only DVI output.

Parameters
timingSource timing. Active dimensions must be nonzero; sync widths are 1 to 255. Horizontal and vertical totals must each fit in 16 bits. pixelClockMHz must be finite and positive, VIC 0 to 127, and aspectRatio 0 to 2.
lanesNumber of DSI data lanes, 1 to 4, without lane or P/N swapping.
Returns
True on success; false for invalid settings, missing begin(), or I2C failure. A partial I2C failure may require reset() before retrying.
Note
This configures the bridge only. The DSI source must generate matching timing and pixel clock; pixelClockMHz does not program the source clock here. The defaults retain Espressif's 25 MHz reference-crystal initialization.
