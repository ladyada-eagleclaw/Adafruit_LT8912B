Detailed Description

ESP32-P4 host setup, separate from the portable I2C bridge driver. Requires Arduino ESP32 3.3.11 or a compatible IDF 5.5 build and PSRAM. The caller owns the bridge and must keep it alive until end().

Start two-lane RGB888 DSI and configure the bridge for video-only DVI.

Parameters
bridgeBridge whose begin() has already succeeded.
timingMatching DSI and bridge timing; pixel clock is in MHz.
buffersNumber of panel-owned framebuffers, from 1 through 3.
laneBitRateMbpsDSI rate per lane in megabits per second.
Returns
True on success. Failure releases partially allocated host resources.
Note
Uses P4 internal PHY LDO channel 3 at 2.5 V. begin() is single-owner; call end() before changing timing. This does not configure the I2C pins.
